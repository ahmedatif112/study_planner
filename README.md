# My Study Planner

A Flutter mobile app that helps a student plan study goals. The student can add goals, mark them as done, delete them, and see live statistics. Goals are saved in the cloud with Firebase Cloud Firestore, so they are still there when the app is reopened.

Built for the Mobile App Development (Dart & Flutter) final project at UNILAK.

## Features

- Add a study goal (subject and planned hours) on a separate screen
- Input validation: subject cannot be empty, hours must be a number greater than 0
- Mark a goal as done (strike-through) or undo it
- Delete a goal
- Live statistics: total hours, completed goals, remaining goals
- Friendly message when there are no goals
- Loading spinner while goals load from the cloud
- Friendly error message if the internet is not available
- Data is saved in Firebase Cloud Firestore and survives closing the app

- `phases/phase5_firebase`: the Firebase Cloud Firestore version of Phase 5, with a screen recording

## How Data Is Saved and Loaded

- **Start:** `main()` calls `DatabaseHelper.initDatabase()`, which connects the app to Firebase.
- **Load:** `initState()` calls `_loadGoals()`, which reads all goals from Firestore with `getGoals()` and shows them on screen. A spinner shows while loading.
- **Add:** the new goal is saved with `insertGoal()`; the document id returned by Firestore is stored in the goal's Map.
- **Toggle:** `updateGoal(id, done)` changes the document in Firestore, then `setState()` updates the screen.
- **Delete:** `deleteGoal(id)` removes the document, then the goal is removed from the screen.
- **Booleans:** Firestore stores true/false directly, so no 1/0 conversion is needed (unlike SQLite).

### Firestore collection: `goals`

| Field | Type | Notes |
|-------|------|-------|
| (document id) | String | Generated automatically by Firestore |
| subject | String | Name of the subject |
| hours | Number | Planned study hours |
| done | Boolean | true = done, false = not done |
| createdAt | Timestamp | Server time, used to keep goals in the order they were added |

## How to Run

1. Install Flutter and set up an Android device or emulator.
2. Clone the repository and switch to the Firebase version:
   ```
   git clone https://github.com/ahmedatif112/study_planner.git
   cd study_planner
   ```
3. Install the packages:
   ```
   flutter pub get
   ```
4. Run the app on an Android device or emulator with an internet connection:
   ```
   flutter run
   ```

Note: the app needs an internet connection to load and save goals. The Firebase configuration is generated for Android only.
